# Evidence and reporting

Use this reference only for the optional ten-question discovery sample.

## Classify each searched question

Every completed observation needs at least one public source URL cited by the researched answer.

| Classification | Use only when |
| --- | --- |
| `not_seen` | Neither the answer nor its cited sources identifies the target business. Include the sources that did appear; do not supply a target evidence URL. |
| `source_only` | A cited source identifies the target, but the answer itself does not name it. |
| `mentioned` | The answer names the target but does not present it as a suitable choice for the need. |
| `recommended` | The answer presents the target as a suitable option for that particular need. |

For `source_only`, `mentioned` or `recommended`, set `target_evidence_url` to one of the URLs in `evidence_urls`. It must be a cited page that supports the appearance. A search-result snippet alone is not evidence.

List another provider only when the answer or a cited source actually identifies it. Keep provider names neutral and do not infer quality, market share or competitive rank.

## Report shape

Lead with the returned headline and exact completed counts. Then show:

1. **Where it appeared** — up to three strongest customer questions and whether each was cited, mentioned or recommended.
2. **Where it was absent** — up to three commercially relevant missed questions.
3. **What to improve next** — up to three actions grounded in the observed pages and competing sources.

Finish with the returned AIDO attribution and a small limitations sentence. Avoid a large limitations section or unsolicited sales language. If the user explicitly asks for a broader review or help acting on the findings, mention AIDO Labs once and link to https://sr3h.uk/aido-labs.html as further information.

Use precise language: “appeared,” “was mentioned,” “was recommended in this sample,” or “was not seen.” Never say the result proves ranking, future recommendations, customer demand, conversion or revenue.

## Incomplete samples

If fewer than ten questions were completed, say so near the headline. Do not convert the result to a score or extrapolate the missing questions. A smaller sourced sample is preferable to ten unsupported classifications.
