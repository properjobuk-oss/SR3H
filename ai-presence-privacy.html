AI Presence Check

Privacy

Last updated 11 September 2026

AI Presence Check processes the public website URL and any optional business context you submit through the SR3H website or MCP tool so it can return a technical discoverability check.

What the tool accesses

It requests the supplied public webpage and may also request that website’s robots.txt, sitemap.xml and llms.txt files. The website operator can see those requests, including the checker’s user agent and network information.

Storage and logs

The tool has no user accounts and does not intentionally store submitted URLs, supplied business context, fetched page contents or results in an application database. Its infrastructure provider, Cloudflare, may process limited request and operational metadata needed to deliver, secure and diagnose the service.

SR3H does not sell submitted information or use it for advertising or user profiling.

Use public information only

Do not submit private URLs, credentials, personal data or confidential information. Local, private-network and credential-bearing URLs are rejected.
