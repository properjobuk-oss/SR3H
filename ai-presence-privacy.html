AIDO Discoverability Check

Privacy

Last updated 12 September 2026

AIDO Discoverability Check processes the public website URL and any optional business context you submit so it can inspect website access and clarity. The SR3H website form can also run a small branded and unbranded discovery sample. The ChatGPT MCP does not run that paid sample.

What the tool accesses

It requests the supplied public webpage, up to four relevant pages on the same website, and may request that website’s robots.txt, sitemap.xml and llms.txt files. The website operator can see those requests, including the checker’s user agent and network information.

AI-assisted analysis

When the live sample in the SR3H website form is available, bounded public-page extracts and the optional context you supplied are sent to OpenAI to assess six relevant questions and run a small web-search sample. The request is sent with API response storage disabled. The MCP tools do not use SR3H's OpenAI API key. An optional extended check in ChatGPT uses research tools available in that user's ChatGPT session. Do not submit personal, private or confidential information.

Storage and logs

The tool has no user accounts and does not write submitted URLs, supplied business context or fetched page contents to an application database. A completed discovery result may be held in Cloudflare’s edge cache for up to 24 hours to avoid repeating the same paid check. Cloudflare and OpenAI may process service and operational data under their own terms.

SR3H does not sell submitted information or use it for advertising or user profiling.

Use public information only

Do not submit private URLs, credentials, personal data or confidential information. Local, private-network and credential-bearing URLs are rejected.
